# Prana

[Прототип на Vercel](https://prana-01.vercel.app) · [Веб-проект и инструкция запуска](Web/README.md) · [Журнал проекта](Web/PROJECT_LOG.md)

Весь проект находится в **Web/**, приложение — **Web/prototype/**.

```sh
git clone https://github.com/Chosencorrectly/Prana.git
cd Prana/Web/prototype
npm ci
npm run dev -- --host 127.0.0.1 --port 5180
```

Node.js 24.x. Desktop-прототип без backend и реальных платежей.
