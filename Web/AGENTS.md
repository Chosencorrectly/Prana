- Read its current state before substantive work. Follow the latest user instructions when they supersede historical decisions.
- After each completed iteration that changes the design, prototype, catalogue, scope or accepted decisions, update the log before handoff. Documentation maintenance is already authorized; do not ask again.

- `prototype/design-qa.md`, `prototype/README.md` and the Figma ledgers provide supporting detail; update them when their subject changes, without making them competing project status reports.
