# Prana — цветовая палитра

Подготовлено 05.10.2026. [Открыть стенд](http://127.0.0.1:5180/design/colors/index.html).

Источник: [Geist Colors](https://vercel.com/geist/colors). Импортированы Backgrounds, Gray, Gray Alpha и оригинальный Amber для светлой и тёмной тем. На каждую тему приходится 32 исходных значения: 2 + 10 + 10 + 10. Дополнительно подготовлен Prana Amber по 10 ступеней на тему, с точным `#EA5C00` на ступени 700.

Пользователь выбрал точные HSL-значения после проверки в DevTools: общий фон `hsl(0 0% 0%)`, кнопки и теги `hsl(0 0% 15%)`. Карточка остаётся #101010 из [Figma 41:7245](https://www.figma.com/design/ANXj1DxD2mm9ZcxNNoNLdE/Prana-Web?node-id=41-7245). Эти три назначения записаны в рабочей палитре с происхождением; оригинальный снимок Geist сохранён. Светлые уровни пользователь подтвердил, они сохранены. Gray Alpha, светлая тема и Amber не менялись; Amber пока не назначен компонентам.

## Применение в каталоге

Назначения хранятся в [theme.css](../../prototype/src/styles/theme.css), рабочие токены копируются генератором в `prototype/src/styles/palette.css`. Номера Backgrounds не задают порядок светлоты: в тёмной теме 200 темнее 100. CSS и JSON `value` сохраняют выбранный синтаксис HSL. HEX на стенде — округлённое представление; копирование выдаёт каноническое HSL-значение. 15% — точно 38,25 из 255, а #262626 — его округление, поэтому исходный HSL не заменяется HEX.

| Роль | Рабочий токен | Значение |
| --- | --- | --- |
| Общий фон, хедер и фейды категорий | Background 200 · Prana / user | hsl(0 0% 0%) |
| Фон карточки | Background 100 · Prana / Figma | #101010 |
| Кнопки внутри карточки, теги и kcal | Gray 200 · Prana / user | hsl(0 0% 15%) |
| Нажатая кнопка внутри карточки | Gray 300 | #292929 |
| Основной текст, цены и числовые КБЖУ | Gray 1000 | #EDEDED |
| Описание, вторичные подписи | Gray 900 | #A1A1A1 |
| pr / fa / ca, kcal, From, Deliver to | Gray 600 | #878787 |

Предыдущий вариант #1A1A1A / #1F1F1F был заменён на заливки Figma, затем пользователь закрепил фон и контролы точными значениями HSL. Прочие примитивы сохранены, в том числе промежуточный Gray 100 #1A1A1A. Правила, пользовательский выбор и node ID карточки находятся в [prana-dark-overrides.json](prana-dark-overrides.json); JSON токена содержит первоначальное значение и происхождение. Это настройка Prana, не изменение официальной шкалы Geist. [Проверка точных токенов](../../prototype/reference/user-hsl-audit.json).

На вычисленных браузером цветах третичный `#878787` на `#262626` даёт **4,21:1**, ниже 4,5:1 для обычного текста. Цвет сохранён по прямому указанию оставить светлые уровни. Описание на карточке — **7,36:1**, заголовок — **16,25:1**. При нажатии кнопка использует Gray 300 без снижения непрозрачности, а From становится вторичным (#A1A1A1). Светлая заливка выбранной категории, Cart и Download App использует Gray 1000 с чёрным текстом. Подложка kcal остаётся непрозрачной, чтобы контраст не зависел от фотографии. [Актуальные измерения](../../prototype/reference/figma-surfaces-audit.json); [предыдущая итерация](../../prototype/reference/raised-card-surfaces-audit.json).

Повторная генерация из корня проекта: `node design-work/colors/generate.mjs`. Исходный снимок автоматически не обновляется. Папка в `prototype/public/design/colors/` генерируется; редактировать следует файлы в этой папке `design-work/colors/`.

Сохранена **sRGB-ветка** сайта. Geist также использует P3 при поддержке дисплеем; эти переопределения в текущий экспорт не входят. Нетронутые HSL-значения оставлены дословно в CSS, а HEX в стенде — их представление с округлением до 8 бит. Оригиналы изменённых значений сохранены в `geist-source.json` и метаданных `palette.json`. Для Gray Alpha сохраняется точный восьмизначный HEX, включая исходный альфа-канал; полупрозрачные цвета не заменены плоским серым.

## Структура шкал

Сохраняем [распределение ролей Geist](https://vercel.com/geist/colors): 100–300 — фоны компонентов; 400–600 — границы; 700–800 — акцентные заливки; 900–1000 — текст и иконки. Backgrounds — отдельные фоновые значения 100 и 200. Это ролевая система, а не равномерный градиент: некоторые соседние номера не следуют строгому порядку светлоты. Такие особенности исходных шкал не исправлялись.

## Как получен Prana Amber

1. Ступень 700 выбрана как основной акцент и в обеих темах закреплена ровно на `#EA5C00`. В OKLCH это приблизительно `0.650788 0.192141 43.175581°`.
2. Оттенки оригинального Amber переведены в OKLCH. Их светлота пересчитана относительно исходной ступени 700: кусочно-линейно между чёрным, новым якорем 700 и белым. Поэтому сохраняется структура исходных ступеней, а не задаются произвольные шаги HSL.
3. Цветовой тон установлен по новому якорю; chroma масштабирована по отношению к исходной ступени 700. При выходе за sRGB chroma уменьшается с сохранением светлоты и тона. Используются стандартные преобразования sRGB/Oklab из [модели CSS Color 4](https://www.w3.org/TR/css-color-4/#ok-lab); само правило адаптации — решение для Prana.
4. Для текстовых ступеней 900/1000 отдельно проверяется контраст с обоими Backgrounds и Amber 100–300. Если нужно, светлота минимально сдвигается в сторону цвета текста темы, с повторной проверкой после HEX-округления. В тёмной теме Amber 900 скорректирован с `#D95500` до `#E45F17`.

| --- | --- | --- |
| 100 | `#240700` | `#FFEBE3` |
| 200 | `#2A0A00` | `#FFE5DA` |
| 300 | `#401300` | `#FFDCCD` |
| 400 | `#4A1800` | `#FFB191` |
| 500 | `#5C1F00` | `#F88959` |
| 600 | `#D15100` | `#DC6328` |
| 700 — основной | **`#EA5C00`** | **`#EA5C00`** |

| 900 | `#E45F17` | `#812F00` |

## Проверки и границы применения

- На этапе импорта все 64 оригинальных образца совпали с исходной страницей. Сейчас карточка помечена Prana / Figma, фон и контролы — Prana / user. На стенде 42 образца на тему; после текущего изменения проверено копирование точного `hsl(0 0% 15%)`. Проверки переключения тем относятся к предыдущей итерации.
- Генератор проверяет комплектность, уникальность и сохранение исходных токенов до явных переопределений, запрет изменения светлых уровней, точный якорь Amber и преобразование контрольных цветов туда и обратно. Переопределения применяются после расчёта Amber, чтобы новый фон не изменял его оттенки.
- 28 проверенных сочетаний Gray/Amber 900/1000 с фонами прошли порог 4,5:1 для обычного текста; минимальный результат — 4,5365:1. Метод: относительная яркость WCAG 2, см. [WCAG Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
- На `#EA5C00`: белый `#FFFFFF` даёт **3,48:1**, чёрный `#000000` — **6,03:1**. Белый не достигает AA для обычного текста; чёрный достигает. Цвет текста на будущих кнопках нужно выбирать с учётом этого результата.
- Это проверка перечисленных пар, не аудит контрастности сайта. Gray Alpha зависит от подложки; остальные сочетания, включая границы и состояния компонентов, проверяются при назначении ролей.
- Отдельный `cataloguePairs` содержит реальные назначения фонов и проверочные сочетания: Gray 600 на control/pressed ниже 4,5:1. В нажатой кнопке From фактически использует Gray 900, а не Gray 600. Генератор сохраняет обнаруженное ограничение, не корректируя светлые цвета вопреки запросу.
- На этапе подготовки библиотека не была подключена к каталогу. Следующая итерация применила нейтральные роли; сборка и desktop-проверка прошли, подробности — в [QA](../../prototype/design-qa.md).
