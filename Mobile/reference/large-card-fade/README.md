# D-67 — читаемость большой карточки

16.10.2026, Europe/Moscow. Реализовано и проверено локально; визуальная оценка пользователя впереди. GitHub/Vercel остаются D-60.

Источник: [обновлённый каталог1194:5225](https://www.figma.com/design/sVUfk3wL7MabAwk1PIV1fv/Prana-App?node-id=1194-5225), большая карточка1291:970, fade1292:1017. Получены high-fidelity design context и [отдельный кадр](figma-card.png). В Figma карточка398×457, fade303px от y154; цвет rgba(18,18,18,.8) достигается на48.472% его высоты. Пользователь обозначил макет ориентиром начала/видимости и разрешил плавную адаптацию.

## Реализация

- Прежний300px градиент набирал80% непрозрачности только на нижнем крае. Новый303px градиент достигает той же плотности на50%, около y305.5 карточки. Поднята именно плотная часть: название/описание лучше отделяются от фото, верхние154px фото остаются без затемнения. Цвет/максимальная плотность сохранены.
- Правило применяется ко всем большим ProductCard. Малые карточки, реальные фото/данные, геометрия текста, кнопок и тегов не менялись. Новые runtime assets не нужны.
- DishDetail считывает реальную высоту и stop исходного псевдоэлемента один раз при открытии. Stop плавно50→100% при раскрытии и100→50% при возврате в большую карточку; у малой остаётся100%. Конечный PDP fade/blur прежний. Сохраняются одна photo/fade/blur-поверхность,420/320ms и исходный контент opacity1 без отдельного проявления.

## Проверка

- IAB/iPhone430×932: Acai до/после на одном scroll0 и Prana oats с четырёхстрочным названием на светлом фото; кадры просмотрены. Computed fade302.986px/stop50% (округление браузерного масштаба).
- Большая карточка открывается/закрывается: промежуточные stop97.30→98.84% при входе, финальные100%; при выходе50.84→50.01%, opacity поверхности→0, исходный content opacity1/transition0s. Финал: overlay удалён, scroll0, фокус View Acai. Это выборки конца перехода, не замер FPS.
- Открытие/закрытие малой Chia проверено, stop100% сохраняется. Покупка, checkout, native touch, Pixel и системный reduced motion в этой итерации не перепроверялись.
- npm run build: TypeScript/Vite/упаковка passed; protected runtime29 passed. Существующие catalog5+dish5 =10/10. Новые тесты для визуальных значений не добавлялись. Console warn/error0; исторический warning JS>500kB остаётся.

## Выжимка для лида и разработки

На больших превью-карточках подняли плотную часть затемнения к названию блюда. Текст лучше отделяется от ярких и пёстрых фотографий, при этом верх фото остаётся открытым. Переход к подробной карточке и обратно согласован с новым градиентом, без отдельного появления текста. Для разработки: нижний gradient303px, transparent→#121212/80% на50% высоты; stop интерполируется к100% в PDP. Изменение локальное, без публикации.
