## Демонстрация состояний

Внизу слева **за пределами телефона** — «Состояния корзины». Закройте текущую корзину, чтобы выбрать сценарий. Панель скрыта во время модального сценария. Каждый запуск создаёт отдельную демокорзину: Acai×2, Chia×1, Buddha×1 = **3 строки / 4 порции / $63.80 / 2350 kcal / 62 pr / 104 fa / 310 ca**. Обычная корзина из меню сохраняется; демозаказ из preview использует отдельный ActiveOrderProvider и не заменяет обычный активный заказ. Промокод и телефон preview также отдельные; адрес остаётся общим существующим контекстом.

Загрузка длится2,4с, повтор после ошибки900ms — только параметры демонстрации. Лимит Acai2 действует только в соответствующем сценарии: уменьшение разрешено, быстрые плюсы не обходят предел. В сценарии ошибки первый следующий плюс/минус оставляет прежний выбор, повтор работает. Уведомление исчезает через6с или по тапу; успешная операция снимает предыдущее сообщение об ошибке/остатке. Toast расположен поверх шапки по макету: пока он показан, тап по перекрытой области закрывает уведомление.

Offline пока демонстрируется как просмотр последнего состояния в памяти: изменение количества, очистка и переход к checkout требуют связи. Это временное правило реализации для проверки макета, не подтверждённый бизнес-контракт. Также учитываются события navigator online/offline; реальная сеть/API и серверное восстановление не моделировались. После reload локальный выбор сбрасывается.

## Данные, адаптации и motion

Цена в строке — за одну порцию; итог суммируется в целых центах. Items означает количество единиц, не число уникальных блюд. Пищевая ценность каталога умножается на количество как текущая прототипная база порции; бизнесу нужно подтвердить её. Если хотя бы у одного блюда нет конкретного нутриента, соответствующий итог — «—»; известный ноль остаётся нулём. Полные названия и реальные составы могут делать строки выше макета.

Локальный SF Pro подключён отдельным именем Prana Cart с fallback на существующий шрифт; файлы шрифтов не добавлялись. Иконки и сумка — оригинальные экспорты Figma, [реестр размеров и SHA-256](assets.json). SVG не перерисованы и не растянуты. Фото блюд — прежние87 оригиналов каталога.

Сохранены no-hover, pressed0.78/70ms/150ms, row reveal/removal240ms, число150ms/4px, PDP420/320ms и opacity1 текста исходной карточки. Нижний BottomFade сохраняет blur4/12/34 вне opacity-анимируемых предков; его зона поднята на80px и затемнение усилено, чтобы прокручиваемая строка не мешала итогу. Нижнее подтверждение280ms, уведомление240ms; reduced-motion использует мгновенную геометрию/80ms fade. Системная настройка reduced motion в этой итерации не переключалась.

## Выжимка для лида и разработки

Пересобрали мобильную корзину по обновлённому дизайну. Блюда разделены визуально, КБЖУ видны у каждой позиции и в общем итоге, рекомендации выделены отдельным блоком. Добавлены загрузка, повтор после ошибки, offline, ограничение количества, ошибка изменения, пустая корзина, отсутствие рекомендаций и заглушка фото. Это упрощает проверку заказа перед оформлением и делает сбои понятными без потери выбранных блюд. Существующие переходы и анимации сохранены.
