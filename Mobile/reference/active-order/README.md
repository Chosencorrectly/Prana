## Поведение и motion

Cart → Checkout → Add phone number → SMS1111 → Checkout → Order. Только подтверждённый номер и непустой реальный состав создают локальный заказ. Состав, количества, цены, скидка, выбранный адрес/детали, номер и параметры checkout копируются в независимый снимок. Корзина после этого очищается; Order защищён от повторного нажатия. `flow.reset` убирает возможность вернуться к уже оформленному checkout. Старые цифры сохраняются на время ухода checkout, без вспышки нулевого Total.

Карта остаётся неподвижной. На430×932 панель имеет верхнюю границу297 /533 /768px. Начальное297 и минимальное768 взяты из макетов; оба компактных исходника показаны на768, хотя notice описывает промежуточную ступень. **533 — выбранная реализационная интерполяция**, которую пользователь может уточнить. Промежуточное состояние показывает часть сохранённого контента; для полного чтения надо раскрыть панель.

Вход: карта240ms, непрозрачная панель62→297 за420ms cubic-bezier(.2,.8,.2,1), статус24px/240ms+80ms. Во время жеста панель следует указателю без easing; после отпускания spring380/39/mass.9, направление/скорость учитываются. Панель и MobileScroll не размонтируются между snap points, внутренний viewport постоянного размера, поэтому scrollTop не сбрасывается и не ограничивается при сворачивании. ETA/status/progress закреплены вне скролла. Show more/less —0fr↔1fr/opacity240ms. Нижний фейд использует общий BottomFade4/12/34 вне opacity-родителя; маска260ms. Reduced motion убирает перемещение и spring; системная настройка вручную не проверена.

Кнопка Expand переключает297↔768, ручка доступна кликом и ArrowUp/ArrowDown/Home/End. Крестик/Escape закрывают всю панель в Menu. Новый shortcut над поиском — адаптация для повторного входа; сохраняются snap,scrollTop,Show more и данные. Только один текущий локальный заказ, новый заказ заменяет этот demo-снимок. После reload состояние сбрасывается.
