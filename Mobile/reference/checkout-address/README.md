## Как проверить

1. Добавить блюдо → Cart → Proceed to Checkout → адрес в Delivery.
2. Выбор в списке только подготавливает адрес. + Add начинает отдельный черновик.
3. Перемещать карту под неподвижным pin мышью; при фокусе карты доступны стрелки. Красная область справа обозначает недоступную часть. При попадании pin туда показано Delivery unavailable here и disabled Continue.
4. Поле Address открывает расширенную панель и клавиатуру. Ввести Brickell; шесть примеров из Figma фильтруются по словам, регистру и пробелам. Выбрать 1000 Brickell Plaza. Поиск закрывается, точку можно уточнить на карте.
5. Continue to details → Apartment, Building, Floor, Access code, Delivery instructions, Address label. Все поля необязательные: геолокация уже определена. Редактирование точки/Back сохраняет заполненные детали. Пустой label при сохранении получает нейтральное Address.
6. Save address добавляет/обновляет запись профиля, выбирает её в списке. Только Deliver here применяет её в checkout, корзине и шапке меню. Сохранение адреса не отправляет заказ.
7. Close возвращает сразу в Checkout без применения кандидата; Back идёт на предыдущий шаг. В списке добавлена кнопка Back to checkout поверх карты. Escape сначала скрывает клавиатуру, затем идёт назад. Сохранённые адреса живут в памяти аккаунта независимо от корзины до reload.

## Адаптации и ограничения

- Pickup исключён из нового адресного сценария по запросу. Прежняя заглушка Pickup на основном Checkout не изменена.
- Карта — исходный bitmap889×1147 из Figma; это интерактивная локальная демонстрация, без провайдера карт, сети, геолокации или настоящего geocoding. Шесть подписей Miami и исходные Home/Work с Bali — fixtures самого макета. Связь пикселей и подписей/граница x610 условны, не географические или бизнес-данные. Pan ограничен краями исходного изображения, zoom не добавлен.
- Поле карты представлено кнопкой входа в поиск с тем же видом; фактический KeyboardInput находится в расширенном состоянии. Результаты остаются внутри sheet и имеют собственный MobileScroll, без dropdown поверх карты.
- Source20px радиусы,15px края,61px поля,54px CTA/bottom28; список2строки top490 (source492),3строки top405 (source409) из последовательных85px строк. Карта top669, warning525, details288, search62 вместо55 из-за калиброванного safe area. Поиск400×408 вместо415. При вводе деталей панель поднимается до62; поля прокручиваются над клавиатурой и Save.
- Оригинальные SVG сохранены неизменными; pin40, radio22, home13, edit18/24, divider370×1. Back18 и close11.6667 в20px слоте повторно используют существующие Figma assets. Work icon воспроизводит два CSS-прямоугольника исходного дизайна. Material Close не установлен в проекте; использован совпадающий локальный glyph, без новой UI-библиотеки. Статус/клавиатура — защищённые компоненты устройства.

## Motion и проверка

Один экземпляр карты и одна непрозрачная поверхность. Top меняется320ms cubic-bezier(.2,.8,.2,1), содержимое — принятый authStep24px/140ms out/240ms in+80ms delay. Центрирование карты320ms, drag следует указателю без задержки. Reduced motion обнуляет движение, opacity≤80ms. Фейды используют общий BottomFade4/12/34 вне opacity-родителей. Выходящие детали сохраняют вид после Save, хотя черновик модели очищается.

TypeScript/Vite/упаковка/integrity29 прошли;23 теста address5/phone4/promo5/motion9 прошли. Проверены в IAB/iPhone mouse/keyboard: поиск/empty, pan за границу и обратно, детали, Back/edit, Save без применения, Deliver here, отмена правки, обновление существующей записи, Escape, сохранение между открытиями. [Аудит](browser-audit.json), [геометрия assets](asset-audit.json), [QA](../../design-qa.md).

Физический touch, системный reduced motion, Pixel, нативная клавиатура и screen reader не проверялись. FPS не измерялся. Прежний Vite warning>500kB остаётся. Backend, настоящий адресный справочник, реальные границы доставки и отправка Order вне этапа.
