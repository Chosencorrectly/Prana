# D-77 — редактируемый код страны на входе

23.10.2026, Europe/Moscow. Прямой запрос пользователя; новый Figma-макет не предоставлялся и не изменялся. Реализовано и проверено **только локально**: http://127.0.0.1:5181/. Пользовательская оценка впереди. GitHub/Vercel не обновлялись, последний публичный выпуск D-76.

## Поведение

- Один текстовый input содержит предвведённый `+1` и национальный номер. Код и `+` можно выделить, заменить, удалить; после очистки они не восстанавливаются сами. Каретка при входе стоит после кода, клавиатура открывается прежним контроллером.
- Флаг определяется по коду из существующего списка 10 демостран. При пустом/частичном коде — нейтральный маркер. Неподдерживаемый код сохраняется текстом, показывает прежнее сообщение о демосписке и блокирует SMS.
- `+1` сам по себе не различает US/CA: default US, явно выбранная Canada сохраняется. IP/регион номера не определяются.
- Список стран доступен через флаг/стрелку. Выбор заменяет код, сохраняя национальные цифры, и возвращает фокус в поле.
- Маска US/CA 3–3–4 сохранена: любые 10 национальных цифр разрешают демо-SMS, лишние цифры остаются видимыми, но блокируют отправку. Другие страны используют прежнее форматирование/длины. Вставка полного `+код номер` заменяет поле целиком, не дублируя код.
- Пробелы — разделители, Backspace/Delete удаляют соседний значимый символ; `+` считается редактируемым символом. Поддержаны выделение и редактирование середины.
- Новый режим включён явно только на входе (`editableCallingCode`). Профиль использует прежнее национальное поле; checkout не переработан. Нет новых зависимостей/assets или изменений protected runtime.

## Выжимка для передачи

На экране входа код страны можно менять прямо в номере, а флаг подстраивается автоматически. Сохранили привычный выбор страны из списка, автофокус и маску; предусмотрели очистку, неполный код, неоднозначный +1 и переполнение. Это упрощает ручной ввод и вставку международного номера, сохраняя предсказуемое редактирование.
