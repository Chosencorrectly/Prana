# D-74 — исправление обычного ввода телефона

22.10.2026, Europe/Moscow. Только локальный Mobile; пользовательская оценка впереди, публикаций нет.

Причина воспроизведена в браузере: при11цифрах с первой1 readPhoneInput удалял её как предполагаемый код страны. После10единиц новый ввод каждый раз вытеснял начало строки. Одновременно AsYouType трактовал первую1 как префикс и не считал1111111111 полным национальным номером.

В phone-model.ts убрана эвристика для строки без+. ДляUS/CA форматирование остаётся3–3–4, полнота проверяется ровно по10цифрам, международная форма строится как+1 и неизменённые цифры. Разделение кода страны выполняется только при явном+. Библиотечный формат/проверка остальных стран сохранены. Переполнение не обрезается и не отправляется. Общая модель используется входом и сменой телефона профиля. PhoneNumberField, protected KeyboardInput/runtime29, визуал и motion не менялись.

Проверено в отдельной IAB-вкладке:

- Поциферный набор1111111111: каретка4/8/12 после3/6/10цифр, кнопка доступна только после10.
- Добавление234 сохраняет все13цифр и отключает SMS;3Backspace возвращают10цифр и доступность.
- Замена первых3цифр выделением на987, вставка5в середине и её удаление: прежние цифры не потеряны, каретка остаётся в месте редактирования.
- Backspace после пробела, Delete перед пробелом, выделение всего номера и очистка.
- Настоящая вставка из clipboard `+1 111 111 1111`; прежнее содержимое clipboard восстановлено после проверки.
- Переключение US↔Canada сохраняет номер и доступность.
- Get the code via SMS → SMS1111 → каталог с номером из10единиц.
- Консоль без ошибок. [Замеры](d74-audit.json), [стабильный кадр](d74-fixed.png). Значения input в DOM-инструменте редактируются защитой приватности, поэтому точные отображаемые цифры проверены по screenshot, а сохранность на каждом шаге дополнительно — модельными тестами.

Добавлены3 регрессионных теста: любые10цифр US/CA (включая0/1), последовательный набор за пределами10без потери начала, явная международная вставка с ведущими0/1. Старое ожидание неявного удаления1 заменено правилом сохранения цифр. `node --test tests/phone.test.mjs tests/auth.test.mjs tests/checkout-phone.test.mjs tests/profile.test.mjs`:27/27passed. `npm run build`: TypeScript/Vitepassed, integrity29passed; прежнее предупреждение JS-chunk>500kB остаётся. Другие suites для этой локальной правки не перезапускались. Физическая мобильная клавиатура/touch не проверялись. Это проверка ввода для прототипа, не подтверждение существования абонента или доставки SMS.
