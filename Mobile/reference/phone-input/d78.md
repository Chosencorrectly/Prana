## Что изменено

Порядок: флаг → редактируемый код → шеврон → национальный номер. Оба подполя — KeyboardInput, без вложенного input в button. Начальный +1 и US сохранены; автофокус в правое поле. Флаг и стрелка открывают прежний список 10 стран. При смене фокуса клавиатура остаётся открытой, focus tint учитывает оба поля.

Код меняется независимо: удаление/частичный/неизвестный код не затрагивает номер. Флаг меняется по точному поддерживаемому коду, общая +1-группа сохраняет явную CA. Вставка полного международного номера в любое подполе распределяет его между кодом и национальными цифрами; вставка только кода слева меняет только код. Маска US/CA, 10 любых цифр для демо-SMS и видимое переполнение сохранены. Профильный режим с фиксированным кодом не менялся.

Убраны неиспользуемые helper и overlay-маска единого input D-77. Ширина кода подстраивается под текст в ограниченном диапазоне; большие ошибочные значения не расширяют весь контрол. Цвета/72px/r20/отступы20px/no-hover/motion/protected runtime29 сохранены. Новый бизнес-список стран/IP/API не добавлялся.
