## Сценарий

- Splash → Sign in → Enter Phone → Enter code → Menu.
- Страна и код выбираются слева от номера; по умолчанию США/+1. Список прокручивается мышью/свайпом, доступен с клавиатуры. Цифры сохраняются при смене страны; международная вставка разбирает код автоматически. Пустой/неполный номер оставляет SMS неактивной. Это проверка возможной длины, не реальная проверка номера. Бали представлен Индонезией/+62; полный список бизнеса и определение по IP ещё не утверждены.
- Проверочный код **1111**. Неполный/неверный код показывает ошибку, верный открывает каталог и завершает стек авторизации. Кнопка Resend доступна после 12 секунд, сбрасывает ввод и запускает новый отсчёт.
- Back сохраняет номер. Reload сбрасывает данные. Переходы организованы через FlowStack, без отдельных URL экранов.
- Skip открывает каталог без ввода номера. Apple / Google и Public Offer / Privacy Policy показывают поясняющие панели: провайдеры и документы ещё не подключены.
- `Plan your whole week` исключён как архивный экран.

## Поиск и нижние контролы — D-49, уточнение D-50

Поиск виден сразу, даже с пустой корзиной. После прокрутки появляется «вверх»; её поверхность с блюром проявляется отдельно от непрозрачной обёртки, без смены фона размытия на последнем кадре. Нижний фейд с прогрессивным блюром остаётся под контролами. При наличии товаров кнопка корзины показывает реальную сумму и видна даже наверху. Отложенный в D-49 переход реализован по новому запросу D-51.

Поиск раскрывается в нижнее поле и поднимается над визуальной клавиатурой. Ввод с физической клавиатуры фильтрует названия, описания и категории по тем же правилам, что desktop. При отсутствии совпадений показаны восемь стабильных предложений из разных категорий. X сначала очищает непустой запрос и возвращает фокус в поле; при пустом поле закрывает поиск и возвращает прежнюю позицию каталога. Enter скрывает клавиатуру, Escape закрывает поиск напрямую. Результаты используют маленькие карточки; открытие блюда и количества общие. [Источник](reference/catalog-search/figma-source.json) · [QA](design-qa.md) · `npm run test:search`.

## Экран и клавиатура

Холст **430×932** помещён в рамку iPhone. Это адаптированная рамка шаблона, без заявления о точной модели iPhone 17 Pro. При уменьшении окна весь телефон масштабируется. Сохранён служебный переключатель Pixel 10, но целевая визуальная сверка этой итерации — iPhone.

Клавиатура — оригинальный статичный PNG из Figma, **430×301**, примерно **32,3%** высоты. Она появляется при фокусе поля и оставляет 631px общей верхней области экрана. Ввод выполняется физической клавиатурой компьютера; нарисованные клавиши не вводят символы. Escape, потеря фокуса и перетягивание клавиатуры вниз закрывают её. Кнопка формы располагается над клавиатурой. Нижняя полоска исходной картинки скрыта, чтобы оставался один системный Home Indicator.

## Структура и проверки

Переходы авторизации используют `authStep`: неподвижная поверхность, сдвиг24px с затуханием, содержимое приходит за320ms, клавиатура — на180–440ms. Между Phone и Code клавиатура сохраняется. Back прерывает предыдущую последовательность; системный reduced motion убирает сдвиги. [Параметры, источники и границы проверки](MOTION.md). Пользователь одобрил анимацию (D-43) и попросил постепенно использовать эти принципы для аналогичных переходов. В мобильном интерфейсе нет hover; кнопки дают pressed-отклик, focus-visible сохраняется для клавиатуры.

- `src/Prototype.tsx`, `src/prototype.css` — экраны и оформление.
- `src/auth-model.ts` — нормализация, демо-код, отсчёт.
- `src/catalog/` — данные, раскладка, каталог и контрол количества; `public/assets/menu/` — 87 оригинальных фото, `public/assets/catalog/` — исходные SVG.
- `src/auth-motion.ts`, `src/mobile/step-motion.ts` — preset и отменяемая последовательность перехода.
- `src/mobile/` — оболочка, навигация, фокус, прокрутка и клавиатура шаблона.
- `public/assets/auth/` — оригинальные Figma-ассеты.
- [Реестр источников](reference/figma-auth-source.json), [визуальная QA](design-qa.md).

```sh
npm run check:runtime
npm run test:auth
npm run test:motion
npm run test:catalog

```

React 19.2.7, TypeScript 7.0.2, Vite 8.1.3, Motion 12.42.2. Build создаёт `dist/client` и сохраняет штатную упаковку шаблона. Сам по себе build ничего не публикует.

Реальные SMS, OAuth, аккаунт, backend, PWA и постоянное хранение отсутствуют. SF Pro подключается из локально установленных шрифтов, с системным fallback; бинарники не включены. Проверка на физическом iPhone и полноценная touch-/accessibility-проверка остаются впереди. Новая мобильная версия не опубликована в GitHub, Vercel или Sites.
